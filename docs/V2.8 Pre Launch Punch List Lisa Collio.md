**Every check above was verified failing as well as passing** — deliberately broken with a planted violation to confirm it catches one — rather than only observed green.

**Build-record additions (why they matter):** `SECTION_JOBS` records source photo, focal point, crop, and the original's git blob SHA for every section image. `OVERLAY_JOBS` does the same for Template A featured images — added 29 July 2026 after a regenerated image had to be reverse-engineered by hash-matching, because nothing recorded which photo or colour variant built it. `generate_header_thumb()` brought the 800×420 card thumbnail into the script; it had been produced out of band, which is precisely why it couldn't be reproduced. **Every generated artifact needs a build record, or it becomes unreproducible the moment it needs changing.**

**`OVERLAY_JOBS` backfilled 30 July 2026 — 36 of 37 slugs recovered, 37/37 confirmed.** Prototyped on 5 slugs first (one with a known answer, to calibrate against), reported the honest result before running the rest — the prototype needed three real debugging rounds (a broken pixel-based band-height detector, an exact-hash criterion broken by font-rendering variance between environments, and a colour-detection bug that silently defaulted to blue on ties) before it reliably reproduced the one known-correct answer. Calibrated against that ground truth (photo-region pixel difference: 0.00 for a correct match, 40+ for wrong), then run across the remaining 36 at ~7s/slug. All 37 rows confirmed by regenerating and diffing the photo region only, which is immune to the font-rendering noise a full-image or byte-hash comparison would flag as a false failure.

## Standing workflow reminders

- Claude Code commits WIP to a feature branch — never `main`, never opening a PR — to survive container reclaim. That is preservation, not publication; the merge gate is unaffected.
- Every instructions file directs Claude Code to commit approved source documents into the repo as its first step, so Lisa never uploads to GitHub manually.
- Section 13: Claude drafts → Lisa approves → merge. Broker sign-off is once, comprehensively, at the end.
- Delete a branch when its PR merges. Leaving one alive is what stranded seven Spanish articles in PR #67.
- **A rule that exists only in a document is not enforced.** Three whole field classes reached production unchecked in one week — alt text, body copy, and description fields — each caught by eye, not by a gate. When a rule is settled, ask whether it can be made mechanical, and scope the check narrowly enough that it does not cry wolf.
