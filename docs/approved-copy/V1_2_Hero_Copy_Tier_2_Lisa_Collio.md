## How to read this

Each page gets a **display headline** (large white text) and a **supporting line** (smaller, beneath it).

**The supporting line IS the H1.** Each page already carries a locked SEO H1. Per the Hero Standard, that H1 remains the actual `<h1>` tag, styled as the supporting line. It is not retyped, not paraphrased, and not replaced by hero copy.

Claude Code reported all twenty-two live H1s on 12 August 2026. Every supporting line below is now the **verbatim existing H1**, except `/blog/` — see below. Where a line reads "existing H1, used as-is," the build must confirm the string still matches the live page rather than trusting this document, since the two can drift.

**One exception, ruled by Lisa on 12 August 2026:** `/blog/`'s existing H1 is *The Blog* (ES: *Artículos en español*). That carries neither topic nor location, and the hero is the page's most prominent line. The H1 is rewritten there — the only page in this set where hero work changes an H1. Because an H1 is SEO-load-bearing, this is a copy change under the Section 13 gate, not a styling decision.

Spanish is written natively in usted register, not translated from the English. Where the two read differently, that is deliberate.

## Compliance notes on this draft

**Checked against the locked rules, item by item:**

- **No superlatives.** No *best*, *top*, *#1*, *leading*, *premier* — in either language.
- **No ambulatory phrasing.** No *walkable*, *walking distance*, *walk to*, or Spanish equivalents.
- **No demographic steering.** No *quiet*, *desirable*, *safe*, *family-friendly*, *tranquila*, *segura*. Cities are described by what is physically there — a downtown, a river, industry, schools — never by who lives there.
- **Service area.** *Goshen and Elkhart, Indiana* throughout. No *Northern Indiana* as a standalone descriptor, no St. Joseph County, no Elkhart County (which appears only inside the verifiable top-20% agent stat).
- **No interest rates**, and nothing time-bound that would date on an evergreen page.
- **Brokerage naming.** *RE/MAX Results, The Viruez Team* in full, with the slash, on the one page that names it.
- **Title.** *Lisa Collio, Real Estate Agent* — comma, never leading with REALTOR®.
- **One language per page.** Every string above sits on a page in its own language.

**Two judgment calls worth flagging rather than burying:**

*"Sell With a Plan, Not a Guess"* implies a contrast with other approaches. It does not name or characterise another agent, so it is not a comparative claim under the NAR Code of Ethics — but it is the sharpest line in the set, and Lisa may prefer something flatter.

*"What the Numbers Actually Say"* carries a faint implication that someone else is saying otherwise. Defensible on a data page, but the same note applies.

**One thing this draft cannot check.** Whether any headline duplicates or contradicts the page's existing H1 — I have not seen them. That reconciliation happens when Claude Code reports, before anything is built.

## What changed in v1.2

**Six Spanish headlines, on five distinct strings. No English changed. No supporting lines changed.**

| Page | v1.1 | v1.2 |
| --- | --- | --- |
| Sellers | Venda con un plan, no con una suposición | Venda con un plan, no a la suerte |
| Moving to Goshen | Su mudanza comienza antes que las cajas | Mudarse bien empieza mucho antes de empacar |
| Moving to Elkhart | Su mudanza comienza antes que las cajas | Mudarse bien empieza mucho antes de empacar |
| Life Chapters | Cada mudanza es un capítulo | Cada decisión abre un capítulo nuevo |
| Market Stats | Lo que dicen realmente los números | Los números, sin adornos |
| Blog | Respuestas, antes de que las necesite | Respuestas antes de que surjan las dudas |

**Why, and it is one reason in five forms.** Every replaced line was structurally English wearing Spanish words — correct grammar, wrong instinct. Lisa raised *suposición* as not sounding authentic; reviewing the full set found four more of the same kind.

- ***suposición*** is a dictionary word rather than a spoken one. *A la suerte* carries the same contrast the way a person says it.
- ***antes que las cajas*** is an English construction. The image needs more scaffolding in Spanish, and *empacar* is the everyday verb.
- ***Cada mudanza es un capítulo*** was the most consequential error. *Mudanza* is the physical act of moving boxes; the English "move" means a life decision. The Spanish read as "every truckload is a chapter" on the page about life stages.
- ***realmente*** was carrying English emphasis Spanish places differently.
- ***Respuestas, antes de que las necesite*** had English comma rhythm. *Dudas* is what people actually call the questions.

**The standing lesson, and it is Volume 37's rule demonstrated rather than stated:** Spanish copy that passes a grammar check can still be translated English. The test is not whether it is correct — it is whether a Goshen seller would say it. That test has to be applied by someone reading it as Spanish, not by comparing it to the English line it sits beside.

**Two Spanish headlines were reviewed and deliberately kept**, so a future session does not assume the whole set was suspect: *Su mudanza comienza…* was replaced on the Moving pages, but *Hablemos de su próxima mudanza* on Contact keeps *mudanza* correctly — that page is about the move itself. And *Una ciudad que vale la pena conocer antes de elegirla* is long but natural, so it stands.
