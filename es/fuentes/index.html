Sobre esta página

Esta página enumera las fuentes usadas para investigar y escribir el contenido de comunidad y área de este sitio web, organizadas por la página o artículo que cada fuente respalda.

Esta lista todavía no está completa para todo el sitio. Por ahora cubre las páginas de comunidad y reubicación de Goshen y de Elkhart que aparecen abajo, junto con sus artículos de autoridad correspondientes. A medida que se publiquen nuevas páginas y artículos, sus fuentes se irán agregando aquí. Si una página de este sitio todavía no aparece en esta lista, eso no significa que su contenido no tenga fuentes — solo que esta página aún no se ha actualizado para incluirla.

Esta información se considera confiable, pero no está garantizada. Las fuentes que aquí se enumeran eran exactas y estaban vigentes en la fecha indicada para cada página. Los detalles de comunidad — nombres de negocios, horarios, eventos y datos similares — cambian con el tiempo, y que una fuente aparezca aquí no garantiza que el dato que de ella se tomó siga vigente hoy. Los negocios, eventos y detalles mencionados se revisan al menos una vez al año; si nota algo desactualizado, avísenos.

Esta página no cubre datos de mercado o de propiedades. Las estadísticas de mercado se obtienen por separado, directamente de la Elkhart County Board of REALTORS® (ECBOR), con la fuente y la fecha indicadas para cada cifra en la página de Estadísticas del Mercado. Esta página tampoco incluye los documentos internos de cumplimiento y marca que rigen cómo se escribe este sitio (normas de vivienda justa, estándares de marca y similares) — solo las fuentes de los datos que el sitio reporta.

Para el descargo de responsabilidad legal completo que cubre este y todo el contenido del sitio, consulte Descargos de Responsabilidad.
