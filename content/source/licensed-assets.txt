# docs/approved-copy/) §5 (positive-provenance record) and created 13 August
# 2026 for the Hero Standard photo build, the first batch to actually need it.

# Format: one entry per asset, with these fields:
#   FILE:            path relative to repo root
#   PHOTOGRAPHER:    who took it (or, for AI-generated content, N/A)
#   TYPE:            "photograph" or "AI-generated illustration -- not a
#                    photograph" (added 17 August 2026, first AI-illustration
#                    batch -- omitted/implied "photograph" on earlier entries)
#   LICENSE:         what right Lisa has to publish it
#   LICENSE ON FILE: where the license/agreement itself is kept (not this repo
#                    — Lisa's own records; not digitized here)
#   EXIF NOTE:       explains missing/foreign camera metadata so a future
#                    check does not mistake it for a rejection signal
#   DOES NOT DEPICT: (AI-generated illustrations only) states plainly that the
#                    image is not a real place, a real person, or property
#                    that could be mistaken for an actual listing -- the
#                    question a future reader will actually have
